# /cn 研究能力复核与数据路线

> 本文保留第一轮9样本升级的研究背景；当前全市场能力、真实覆盖和使用方式以 [全市场升级说明](cn-market-screening.md) 为准。

复核日期：2026-10-18。本文结合当前仓库实现与原始来源目录，说明研究方法、接入现状和仍需补齐的数据。目录核验日期不代表每条数据的发布日期，也不证明接口今天均可用。

## 本轮实现与覆盖范围

当前 `lib/cn/catalog.ts` 定义20条序列，`providers.ts` 包含财政部文章、东方财富、世界银行和IMF适配器，沪深300由 `equity.ts` 处理。财政部逐点保留原文、发布时间和抓取时间；其他多数序列仅有统计期与本次抓取时间。已有历史分位、同月季节比较、收益率利差、异常检测、事件观察和风险试算。

升级后的 `/cn` 增加“专题与标的”工作区，并扩展“数据与方法”。实际可用的研究流程如下：

- **五个专题**：化债与清欠、消费与内需、工业与再通胀、利率与久期、广谱复苏。每个专题展示传导链、宏观条件、支持/反向/中性/缺失状态、下一项应核对的经营证据和反证条件。阈值由本站定义，条件计数不代表独立证据数量、概率或预期收益。
- **九只人工研究样本**：4只股票、3只权益ETF和2只债券ETF，可按专题、类型、代码或名称筛选，并查看官方入口、经济暴露、研究清单和风险。它们是有限的人工映射，尚未建立全市场动态筛选模型。
- **腾讯证券报价**：研究页打开时每5分钟检查一次，显示价格、涨跌幅、个股PB和上游报价时间。PE(TTM)口径未独立核验，保持缺失；ETF不套用个股PB。报价可能延迟，不能声称已接入交易所授权实时行情。[腾讯行情入口](https://gu.qq.com/)
- **四只股票财报验证**：对中国建筑、招商银行、三一重工和长江电力读取东方财富转引的利润表、资产负债表与现金流量表。展示营业总收入、归母净利润、经营活动现金流净额、应收账款、总资产、总负债和股东权益合计；取三表均有数据的最近报告期，与上年相同报告期比较，并列出报告期、转引公告日和获取时间。银行应收账款标为不适用，现金流与负债另给银行口径说明。[东方财富财报入口](https://data.eastmoney.com/bbsj/)
- **手动情景分析**：股票输入买入价、基期EPS、增长、退出PE和现金分红；债券ETF输入修正久期、利率冲击和持有收益。只在输入有效时计算，未自动生成盈利预测或目标价；权益ETF展示产品与估值核验清单。
- **个人研究记录**：在当前浏览器保存观察清单、假设、支持证据、失效条件、原文链接和下次复核日期。复核日期只是记录；没有跨设备同步或自动提醒。
- **JSON研究快照**：下载当前专题、宏观证据、该专题证券报价、已加载财报、当前及已访问标的的情景输入和已保存笔记，保留来源与时点。切换标的会重置情景表单，已访问输入按证券ID留在本次会话的导出数据中；未保存笔记不会被导出。它不是历史当时可知数据集，尚未提供导入恢复功能。

以上能力按 `components/cn/research-workspace.tsx`、`components/cn/fundamentals-panel.tsx`、`lib/cn/opportunities.ts`、`lib/cn/security-catalog.ts`、`lib/cn/securities.ts` 和 `lib/cn/fundamentals.ts` 核对。后续版本若改变覆盖范围，应同步修改本文及来源目录。该实现提供接近机构工作流程的研究工具，未取得任何机构认证，也未接通付费机构数据库。

财报适配器每张表只请求最近12个记录，使用当前修订值，不宣称完整财务历史。利润和现金流为年初至报告期末累计，资产负债为期末存量；仅当前后值都存在且上年基数为正时计算同比百分比，否则保留金额差与缺失状态。财报附注、合同资产、分部收入、净息差、不良率、拨备及资本充足率尚未全面接入，不能自动完成清欠到账或银行资产质量判断。

## 机构数据体系如何落地

机构研究的可复核性来自统一口径、来源追溯、时间对齐和证据闭环。仅增加指标数量，不能证明因果或改善投资结果。

### 第一层：免费原始发布

- **国家统计局**：总量与行业分项、价格、收入、就业和库存等是需求与生产研究的基础。发布日历明确：国家数据的进度指标通常在新闻稿发布后约3个工作日更新，数据库抓到新值的时间不等于市场首次获知时间。原始新闻稿、数据库值及修订记录应分别保存。[发布日历](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)、[国家数据说明](https://data.stats.gov.cn/staticreq.htm?eqid=8342caf1001611ab0000000464568341&m=aboutctryinfo)
- **人民银行**：社融与贷款结构帮助区分政府融资、企业融资和居民融资；总量增加不能直接推出资金流入股票或私人需求复苏。原始分类与货币统计口径需随公告维护。[金融统计入口](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/index.html)
- **财政部及地方财政部门**：发行、还本付息、余额、预算决算与资金用途应分别建表。发行文件证明融资发生，资金使用报告与企业公告才可能验证清欠实际落地。[地方债统计](https://zwgls.mof.gov.cn/tjsj/)、[官方地方债月报样例](https://zwgls.mof.gov.cn/tjsj/202607/t20260727_3994357.htm)
- **海关与外汇局**：海关商品、目的地、数量和金额有助于建立出口产业链；外汇局结售汇与跨境收付款用于交叉验证。海关货物贸易和国际收支货物贸易须保留各自口径。[海关统计服务指南](https://online.customs.gov.cn/static/pages/guides/002029004002/002029004002.html)、[海关数据查询说明](https://www.stats.gov.cn/zs/tjws/zytjzbqs/zckze/202501/t20250121_1958385.html)、[外汇局统计](https://www.safe.gov.cn/safe/tjsj1/)

本路由尚未自动接入以上全部分项。目录中列出的能力描述是来源提供什么，接入状态描述的是本站已经取得什么，两个字段不能混用。

## 从专题到具体标的

下面是研究流程设计，不是基于2026-10-18最新财报和价格计算出的投资结论。任何当前机会判断都应重新检查数据和估值。

1. **写出可被否定的假设。** 例如“清欠改善某类企业经营现金流”，应明确研究期限、涉及地区和预期出现的财报项目。
2. **定义先行、确认与反证数据。** 先行观察政策与融资；确认看订单、回款或利润；反证检查补贴退出、需求透支、库存积压、成本上升或持续负现金流。
3. **建立标的身份与暴露。** 从指数、交易所名单和财报业务分部得到候选；记录证券代码、上市市场、主营产品、地区和客户。主题概念标签只能用于检索。
4. **检验企业兑现。** 对照原始报告中的收入、毛利、现金流、应收账龄、减值、净债务与资本支出；银行、工业企业和REITs使用各自适用的指标。
5. **把当前价格放进情景。** 估值输入必须标日期、来源和单位。乐观/基准/压力情景分别改变盈利与估值倍数；未取得一致预期时，由用户输入自己的假设并明确标记。
6. **选择交易工具并持续复核。** ETF核对指数、集中度、费率、跟踪误差、折溢价和成交；个股补充财务质量和治理风险；记录失效条件与下一次数据发布要检查什么。

### 普通人能执行的ETF研究示例

若假设是广泛的内需和企业盈利修复，先用需求与信用数据核验，再查看宽基指数的行业分布。当前候选池包括沪深300ETF华泰柏瑞 `510300`。进一步比较同指数产品时，可以到上交所名单查沪深300ETF华夏 `510330` 等；`510330` 是研究方法示例，未纳入本页报价白名单。每次比较都要重新取得规模、成交、费用和跟踪误差，不能由代码名单自动得出产品优劣。[交易所基金名单](https://www.sse.com.cn/assortment/fund/list/?type=5)

若研究的是某一个产业，先查指数规则和持仓，确认产业收入暴露，再比较跟踪该指数的ETF。若转向个股，继续核验业务分部和财务质量；宏观改善本身不能替代企业经营证据。

估值工具可使用“假设每股收益×假设市盈率”演示价格敏感性，但金融企业、亏损企业和周期高点企业不应机械套用。银行可结合PB与ROE、资本和信用成本；工业企业结合正常化盈利、自由现金流与净债务；REITs结合经营现金流与资产剩余期限。情景结果是输入假设的数学结果，不能被标为目标收益承诺。

## 后续数据工程验收标准

新增一条数据源之前，应先定义字段、单位、频率、季调口径、地域范围和修订规则，并取得与实际用途匹配的访问资格。为每个观察值保存：

```text
seriesId / securityId
observationPeriod（经济或财报所属期）
publishedAt（首次公开时间，未知时为空）
fetchedAt（本站获取时间）
vintageId（版本，未保存时不能伪造）
sourceUrl / sourceOrganization / transportProvider
unit / basis / adjustment / value / qualityFlags
```
